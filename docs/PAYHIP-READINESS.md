# Payhip — évaluation historique, non sélectionnée

Ce document conserve une évaluation antérieure de Payhip. **Payhip n'est pas connecté, n'est pas l'intégration active et ne doit pas remplacer le checkout existant sans demande explicite du propriétaire.**

La voie actuellement présente dans le dépôt est PayPal Classic/IPN. La priorité est de terminer et vérifier cette intégration existante, les associations WAV et la livraison sécurisée. Aucun abonnement Payhip ni autre nouveau prestataire ne doit être engagé dans le cadre de cette reprise.

Les notes ci-dessous sont historiques et ne constituent pas une décision d'intégration.
